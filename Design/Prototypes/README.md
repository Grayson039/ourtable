# HTML Prototypes

Interactive HTML prototype screens for OurTable — all 8 modules.
These are the Phase 3 design deliverables, built before the React Native app.

## Files (move here from `screens/`)

| File | Module |
|------|--------|
| `01-auth-onboarding.html` | Onboarding flow |
| `02-home-search-library.html` | Home, Search, Library |
| `03-recipe-detail.html` | Recipe Detail + Cooking Mode |
| `04-add-recipe.html` | Add Recipe (import flow) |
| `05-fridge-pantry.html` | Fridge & Pantry |
| `06-grocery-list.html` | Grocery List |
| `07-profile-settings.html` | Profile & Settings |
| `08-recipe-book.html` | Recipe Book |

These prototype screens reference `our-table-design-system.js` in the repo root.
